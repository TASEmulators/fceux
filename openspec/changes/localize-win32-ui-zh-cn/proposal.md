## Why

FCEUX 的 Win32 前端目前只提供英文界面，菜单、对话框及运行时提示中还包含大量模拟器和 TAS 专业术语，直接逐字替换容易造成术语误译、遗漏和界面回归。需要以英文可回退、术语可审查、改动不影响模拟核心的方式提供一致的简体中文界面。

## What Changes

- 为 Win32 前端增加 `English`、`简体中文` 和跟随 Windows 显示语言的自动选择，并持久化用户的显式选择；英文继续作为默认基准和缺失翻译回退。
- 本地化 Win32 主窗口菜单、对话框、工具窗口、TAS Editor、调试工具、消息框、状态提示和文件选择器等面向用户的界面文案，同时保持快捷键、格式占位符、资源 ID、配置键和模拟行为不变。
- 建立可审查的简体中文术语表和翻译准则：NES、FCEUX、TAS、Lua、ROM、RAM、PPU、APU、FDS、NTSC、PAL、FPS、FM2/FM3 等通行缩写保留；含义稳定且大众熟悉的操作词使用中文；容易歧义或首次理解成本较高的 TAS 术语采用“中文（英文）”或保留英文。
- 使用编译期 Win32 语言资源承载菜单、对话框和字符串表；动态文案通过统一的宽字符加载与格式化入口取得译文，避免依赖系统 ANSI 代码页，并在译文缺失时安全回退到英文。
- 增加资源完整性、占位符/助记键一致性和关键界面冒烟检查，防止新增英文文案未登记、翻译遗漏或中文文本被截断。

## Capabilities

### New Capabilities

- `win32-ui-localization`: 定义 Win32 UI 的语言选择、简体中文覆盖范围、术语处理、英文回退、Unicode 显示和完整性验证行为。

### Modified Capabilities

无。

## Impact

- 主要影响 `src/drivers/win/res.rc`、新增的简体中文资源/术语清单、`src/drivers/win` 中产生用户可见动态文案的代码，以及 Visual Studio/CMake 的 Win32 资源构建配置。
- 新增一个仅限 Win32 前端使用的轻量本地化辅助层和语言配置项；不改变模拟核心、ROM/存档/电影文件格式、命令行兼容性或 Qt/SDL 前端。
- 不引入第三方运行时本地化库；英文资源始终随程序提供，因此语言资源不完整或语言设置无效时仍可正常使用。
