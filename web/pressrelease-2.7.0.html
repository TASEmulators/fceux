FCEUX 2.7.0 Feature Release

October 2026

The 2.7.0 release introduces several new features and improvements focused on build system enhancements, media codec support, and developer tooling. Profiling and debugging capabilities have been significantly improved, with support for FFmpeg 9 and enhanced platform compatibility.

Common

Build System

Build system optimizations for faster compilation times.
Added Linux thread sanitizer build support for improved debugging and memory safety analysis.
Fixed build compatibility with older SDL2 versions that lack SDL_GetTicks64 function.
Implementation of vcpkg build cache to reduce build time for Windows builds.

Qt/SDL

Media Support

Added support for FFmpeg 9 for enhanced video encoding compatibility and codec support.

Developer Tools

Integrated profiling tools for comprehensive performance analysis and optimization.
Added configurable flag to control whether profiling tools are enabled.

Platform Support

Qt6 build improvements for better Linux support.
Fixed Qt Wayland screenshot functionality with improved stability.
Enhanced Qt/SDL screenshot handling with improved error reporting.
Fixed immediate exit issue when SDL video driver is used on Qt Wayland.
Updated Qt win64 auto build to use VS2022 and Qt 6.9.3.
Updated macOS auto build to use Sonoma OS version.

Features

Basic netplay feature (experimental) - enabling multiplayer gaming over the network.
JavaScript/ECMAScript scripting engine for Qt GUI - allows users to create custom UI windows and scripts using Qt's built-in JavaScript engine.

Bug Fixes

Fixed Qt FCEUD_GetTime function to use 64-bit SDL_GetTicks64.
Removed minor memory leak on application shutdown.
Fixed profiler disabled macro.
Cleaned up compiler warnings related to set but not used variables.
