What's New? 2.8.0 (changelog)

What's New? 2.8.0

Released -- 30 November 2026

The 2.8.0 release adds RetroAchievements support, a Lua source debugger, a built-in performance profiler, a gamepad-operated user interface, and a large set of Qt GUI improvements including dark mode, dockable tool widgets, and saved window layouts. It also fixes several memory safety issues in ROM, movie, and file parsing.

Common

Bug Fixes

Fixed heap overflows when loading malformed iNES ROM sizes, UNIF MAPR chunks, and CHR-RAM smaller than 8k.
Fixed out-of-bounds reads in the GUID parser (#856) and in hex string decoding (#857).
Fixed an abort when loading a movie with a negative length header (#858).
Fixed segfaults on mapper 218 (#851).
Fixed save states for VRC7 (#821).
iNES files are now loaded and saved using the raw PRG/CHR sizes from the header instead of power-of-two rounded sizes.

Qt/SDL

RetroAchievements

Added RetroAchievements support with softcore and hardcore modes. Hardcore mode enforces the RetroAchievements rules by restricting speed control, netplay, and the debug and tool windows.
Added local leaderboards, Encore mode, user avatar display, and an unlock sound played through the active audio driver.
Available in the Linux, macOS, and Win64 builds.

Lua Source Debugger

Added a source-level Lua debugger, integrated with the Lua console window and accessible from the main menu.
The GUI now stays responsive while a Lua script runs for a long time without yielding.

Gamepad Operated Interface

Added a gamepad-operated main menu and a gamepad-navigable file browser for opening ROMs (#847).

Board Control

Added a Board Control dialog with interactive DIP switch banks for boards that provide them.

User Interface

Added a built-in dark mode and a set of built-in GUI styles.
Added a dockable State Slot Viewer with savestate screenshots and a dockable State Recorder Timeline.
Added saving and recalling of window layouts for the main window and all debug and tool windows.
Added save state banks, providing state slots 0 to 999.
Added an optional status bar for emulator messages. It is enabled by default.
Added a text overlay shared by all video drivers.
Added an option to take screenshots from the video driver buffer, including scaler effects and overlays.
Added translation loading and a language selector.
Added a Linux option to use X11 on Wayland.

Audio and Video

Added a Qt Multimedia audio driver, with audio output device selection, as an alternative to the SDL audio driver.
QPainter is now the default video driver.
The Vulkan video driver no longer blocks while waiting for vsync.
Faster AVI recording and x264 encoding.

Input

Added an option to automatically enable the Family Keyboard when a ROM is loaded (#797).
Added the 4-Player Adapter to the input settings (#803).
Added LCD zapper support. This has not been tested with real hardware.

Developer Tools

Added a profiler dialog window. It records timing markers from the application's threads to a capture file and displays them in a per-thread timeline viewer with zoom, per-frame browsing, and marker search.
Profiler instrumentation is built in by default (the FCEU_PROFILER_ENABLE CMake option) and adds negligible overhead while not capturing. Builds with the option disabled keep the viewer but cannot record captures.

Bug Fixes

Fixed gamepad hotkey bindings to Turbo not persisting after restart (#667).
Fixed invalid speed configuration parameter names (#752).
Fixed Lua mouse button feedback (#822).
Fixed mouse cursor scaling with the OpenGL video driver on high DPI displays.
ROM open and close, and drag and drop of ROMs and states, are now blocked while the TAS Editor is active.

Build System

The minimum supported Qt version is now 5.15 and the minimum CMake version is 3.16.
Linux, macOS, and Win64 Qt builds are now produced by GitHub Actions.
