## UI Rules

- Translate common actions and options into short Simplified Chinese.
- Preserve user data, file paths, register names, numeric values, and keyboard shortcuts.
- Preserve visible shortcut suffixes after tab separators, such as `Ctrl+S` and `Alt+F4`.
- Use English fallback when a Chinese static resource or dynamic string is missing.
